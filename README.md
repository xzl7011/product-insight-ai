# 需求洞察 AI / Product Insight AI

一个面向产品需求分析场景的 MVP Web 应用。用户输入模糊的产品想法，系统输出结构化的目标用户、核心痛点、功能优先级、用户故事和验收标准。

## 功能
- 产品想法输入
- 结构化需求分析
- 功能优先级展示
- 用户反馈入口
- MVP 演示模式

## 本地运行
```bash
npm install
npm start
```
打开 `http://localhost:3000`

## 技术栈
Node.js + Express + HTML/CSS/JavaScript

## 项目说明
当前版本为 MVP 演示模式，分析结果使用规则化模板生成，并明确标识为 Demo。后续可接入真实大语言模型 API，并增加数据库、用户登录和反馈分析功能。

## 个人项目价值
项目聚焦产品岗位常见工作流：需求输入 → 需求分析 → 功能优先级 → 用户反馈，为后续迭代提供闭环。
